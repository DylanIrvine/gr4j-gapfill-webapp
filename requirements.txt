# that works locally. numba pins a numpy ceiling; leaving these unpinned lets pip
# install an old numba, which drags numpy backwards and breaks the scikit-learn /
# scipy ABI (an ImportError at the core.gapfill import). numba 0.62 supports
# numpy < 2.4, so the two ranges below cannot conflict.
#
# Set the deploy Python version to 3.12 or 3.13 (Streamlit Cloud: app settings,
# not runtime.txt). numba 0.62 has wheels for both.
