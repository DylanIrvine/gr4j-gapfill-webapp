# HydroSTITCH
Hydrological Signatures, Time-series Infilling and Tools for Catchment Hydrology

GR4J/5J/6J calibration, gap filling, uncertainty analysis and baseflow separation web application. Automates
the calibration of parameters, gap fills hydrographs, and performs a range of common hydrological analyses.

Written by Dylan Irvine
Charles Darwin University
